Registro e numerazione PP

I PP prodotti non vengono archiviati come file PDF. L’app conserva invece nel registro condiviso tutti i dati utilizzati per generarli, così ogni PP può essere rigenerato in qualsiasi momento. Il numero è assegnato automaticamente in progressione per la UM.

Codice di recupero amministratore

Serve solo per reimpostare la password dimenticata. Conservalo separatamente e condividilo esclusivamente con chi è autorizzato all'amministrazione.

Password amministratore

Backup / ripristino dati

Il file Excel di backup contiene anagrafica, progressive chilometriche, identificazione del sezionatore, tutti i controlli, anomalie, interventi e note. Può essere usato per ripristinare automaticamente il censimento. Password e codice di recupero non vengono esportati.

Reset applicazione

Ripristina l'app come una prima installazione. Verranno cancellati configurazione UM, anagrafica, verifiche, dati locali e collegamento salvato all'archivio. L'operazione richiede nuovamente la password amministratore e una doppia conferma.

Reset completo applicazione

Questa operazione riporta il censimento allo stato di prima installazione. Verranno eliminati anche i dati presenti nel file JSON dell'archivio attualmente collegato.
